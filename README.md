# Sistema Inteligente de Patrullaje Policial

Backend académico desarrollado con Java 17, Spring Boot 3.3.4, Spring Data JPA, PostgreSQL y Maven.

## Alcance

El proyecto implementa únicamente backend y lógica de negocio: ciudadanos, comunas, CAI, servicios policiales, solicitudes y seguimiento. No incluye frontend.

## Ejecución en Apache NetBeans

1. Configurar JDK 17.
2. Abrir el proyecto como Maven Project.
3. Crear en PostgreSQL una base de datos llamada `patrullaje`.
4. Ajustar `src/main/resources/application.properties`.
5. Ejecutar `SistemaPatrullajeApplication.java`.
